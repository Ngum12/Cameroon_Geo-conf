# Military Background Videos for Authentication Page

## Required Videos

Place the following military-themed background videos in this directory:

### Primary Videos (MP4 format recommended):
1. `military-background-1.mp4` - General military operations
2. `defense-operations.mp4` - Defense force activities  
3. `cameroon-military.mp4` - Cameroon-specific military content

### Video Requirements:
- **Format**: MP4 (H.264 codec recommended)
- **Resolution**: 1920x1080 (Full HD) minimum
- **Duration**: 30-60 seconds (will loop automatically)
- **Content**: Professional military/defense themed content
- **Audio**: Not required (videos are muted)

### Suggested Content Themes:
- Military personnel in action
- Defense equipment and vehicles
- Training exercises
- Strategic operations
- Cameroon flag and military symbols
- Professional military ceremonies

### Fallback:
If custom videos are not available, the system will use a sample video as fallback.

### File Size Considerations:
- Keep videos under 50MB each for optimal loading
- Compress videos for web delivery
- Consider using multiple resolutions for different devices

### Adding Videos:
1. Place MP4 files in this `/public/videos/` directory
2. Update the `militaryVideos` array in `AuthPage.tsx` if needed
3. Test video loading and playback
